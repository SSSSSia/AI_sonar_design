# 拖曳线列阵声呐 CAD 建模知识库

## 系统概述

拖曳线列阵声呐（Towed Array Sonar）是一种被动声呐系统，由拖曳平台（潜艇或水面舰）拖拽一条柔性线列阵进行水下目标探测。系统具有以下特点：
- 基阵孔径大（不受平台空间限制）
- 远离本艇噪声源，探测性能优
- 工作频段低（数十至数千赫兹）
- 适合远程安静目标探测

被动拖曳线列阵由拖线阵、信号预处理设备组成。拖线阵用于水声信号采集；信号预处理设备用于阵列数据转发与存储。

## 系统组成

拖曳线列阵声呐从尾部到头部依次由以下六大部件组成：

1. **尾绳（Tail Rope）**：尾部稳定器，提供拖曳稳定性
2. **16基元声阵段2（Acoustic Segment 2）**：第二段声学模块，含16个水听器基元
3. **16基元声阵段1（Acoustic Segment 1）**：第一段声学模块，含16个水听器基元
4. **前减振段（Damping Section）**：前部隔振段，减少拖缆振动传递
5. **变径汇流头与传输缆（Transition and Cable）**：变径机电汇流头连接高强度传输缆
6. **水密航插（Watertight Connector）**：水密电连接器，连接干端设备

装配顺序：从尾部开始，按上述顺序依次连接，最终通过水密航插连接到潜艇干端设备。

拖线阵列是核心部件，包含声阵段、隔振段、传输缆和尾绳。信号预处理机负责阵列信号的采集、放大、数字化后进行数据转发与存储。操控软件提供人机交互界面，支持系统自检、参数设定和故障报警。附属设备包括便携式包装运输箱和常用安装工具，保障设备的运输与维护。

## 拖线阵列功能指标

### 核心指标
- 阵列直径：不超过27mm
- 工作频率：50Hz～3kHz
- 阵元数目：32（每段16个，共2段）
- 姿态传感器数目：4个（每段2个）
- 阵段长度（含声阵段和间隔阵段）：不超过60m（重点关注声阵段）
- 阵元间距：1.5m±10mm
- 阵列空气中重量：不大于40kg

### 声学性能指标
- 工作频带内阵元灵敏度（不含前放）：不低于-195dB
- 工作频带内阵元灵敏度起伏：不超过±3dB
- 最大工作深度：不小于300m
- 流噪声级：4节航速下噪声级上升不超过16dB@1kHz

### 指标说明
- 阵列直径不超过27mm是拖线阵的物理尺寸约束，影响水动力学性能和布放操作
- 工作频率50Hz～3kHz覆盖了潜艇辐射噪声的主要频段
- 阵元数目32决定了阵列的空间分辨能力和指向性
- 阵元间距1.5m对应最高工作频率约1000Hz时的半波长间距（水中声速约1500m/s）
- 灵敏度-195dB表示水听器对声压的响应能力，数值越高（绝对值越小）越灵敏
- 灵敏度起伏±3dB表示各阵元之间的一致性要求
- 流噪声级是拖曳速度对阵列信噪比的影响指标

## 声阵段设计

声阵段由两条16元水听器阵列组成，每条水听器阵列包含：
- 16个水听器与采集放大组件，水听器间距1.5m
- 1个整合组件
- 2支姿态压力传感器

声阵段是拖线阵的核心功能段，负责水声信号的采集。每个水听器将声压信号转换为电信号，经采集放大组件进行信号调理和数字化。姿态压力传感器用于监测阵段的姿态角和深度信息，为后续信号处理提供空间位置参考。整合组件负责将所有阵元信号汇聚并通过内部线缆传输至信号预处理设备。

### 声阵段内部结构
声阵段采用管状结构，从外到内依次为：
1. 外护套：半透明聚氨酯管，外径不超过27mm，壁厚约3mm
2. 水听器基元：16个，等间距1500mm排列，嵌于管内
3. 采集放大组件：与水听器配对，负责信号放大和数字化
4. 姿态压力传感器：2个，位于阵段内特定位置
5. 对接件：两端钛合金连接套管，用于段间连接
6. 内部线缆：传输信号和供电

### 声阵段内部填充与密封
- 透声填充材料：硅油或聚氨酯凝胶，用于平衡内外水压、减振和声学透射
- 内部导线：屏蔽双绞线，沿管内壁布线，通过卡槽固定
- 密封方式：钛合金对接套筒采用 O 型圈 + 硫化密封，密封等级需满足 5MPa（对应500m水深）

## 声呐探测方程

拖曳线列阵声呐的探测能力由声呐方程决定。在进行系统设计和性能评估时，探测需满足如下声呐方程：

SL - NL - TL + DI ≥ DT

### 声呐方程参数说明
- SL（Source Level）：目标声源级，即被探测目标辐射的声功率级，单位dB。潜艇等目标的SL值可通过情报资料查询，典型值因目标类型和工况而异。
- NL（Noise Level）：环境噪声级，即海洋环境背景噪声的声压级，单位dB。受海况、航运、生物噪声等因素影响，需根据实际作业海域评估。
- TL（Transmission Loss）：传播损失，即声信号从目标传播到阵列过程中的能量衰减，单位dB。通常参考球面扩展损失：TL ≈ 20lgR，其中R是目标与阵列的距离（米）。
- DI（Directivity Index）：指向性指数（阵增益），反映阵列抑制各向同性噪声的能力，单位dB。DI值与阵元数量和工作频率相关，是设计需要优化的核心指标。
- DT（Detection Threshold）：检测阈，即系统能可靠检测目标所需的最小信噪比，单位dB。通常取3dB，工程设计中给出3dB余量。

### 设计应用
声呐方程用于：
1. 根据目标特性（SL）和环境条件（NL），计算所需的最小DI值
2. 根据DI需求确定阵元数目和阵列长度
3. 评估不同工作频率下的探测距离
4. 验证设计方案是否满足探测性能要求

### 设计示例
若需要在特定水深环境下对某目标进行被动探测，要求对声源级为SL dB@f Hz的目标，探测距离不低于R km（对应传播损失TL），则需要设计拖曳阵系统使其DI满足：
DI ≥ DT + NL + TL - SL

### 指向性指数DI与阵元数量关系
线列阵指向性指数近似公式：DI ≈ 10lg(N)，其中N为阵元总数。
- 16阵元（1段）：DI ≈ 12dB
- 32阵元（2段）：DI ≈ 15dB
- 48阵元（3段）：DI ≈ 17dB
- 64阵元（4段）：DI ≈ 18dB
- 128阵元（8段）：DI ≈ 21dB
实际DI还受工作频率、阵元间距和信号处理算法影响，上述为理想线列阵近似值。标准32阵元拖曳阵的系统指标为DI ≥ 16dB，包含了阵列信号处理的综合增益。

### 环境噪声级NL参考值
环境噪声级受海况、航运密度、生物噪声等因素影响，以下为工程参考值：
- 深海（水深大于200m）：50-70dB @ 200Hz，55-65dB @ 500Hz，50-60dB @ 1kHz
- 浅海（水深小于200m）：65-90dB @ 200Hz，60-80dB @ 500Hz，55-75dB @ 1kHz
工程设计中NL取值需根据实际作业海域评估，初步设计阶段可取上述范围中值。

### 设计数值推导示例一（标准参数可满足）
场景：深海环境（水深300m）被动探测潜艇目标，目标声源级 140dB@200Hz，要求探测距离不低于 5km。
计算过程：
1. 传播损失：TL = 20lg(R) = 20lg(5000) = 74dB（球面扩展损失，R单位为米）
2. 环境噪声级：NL ≈ 60dB（深海200Hz频段典型值）
3. 检测阈值：DT = 3dB（工程设计标准）
4. 所需指向性指数：DI ≥ DT + NL + TL - SL = 3 + 60 + 74 - 140 = -3dB
5. 标准拖曳阵评估：32阵元线列阵DI ≈ 15dB，远超 -3dB 需求
6. 结论：标准参数（2段×16阵元、阵元间距1.5m、声阵段总长48m、阵列全长约80m）完全满足要求，设计方案按标准参数执行

### 设计数值推导示例二（需调整阵列规模）
场景：深海环境被动探测安静型潜艇，目标声源级 120dB@500Hz，要求探测距离不低于 8km。
计算过程：
1. 传播损失：TL = 20lg(8000) = 78dB
2. 环境噪声级：NL ≈ 58dB（深海500Hz频段典型值）
3. 检测阈值：DT = 3dB
4. 所需指向性指数：DI ≥ 3 + 58 + 78 - 120 = 19dB
5. 标准拖曳阵评估：32阵元DI ≈ 15dB，不满足19dB需求
6. 参数调整：将阵元数量增至64个（4段×16阵元），DI ≈ 18dB，仍略不足；增至80个（5段×16），DI ≈ 19dB，满足需求
7. 调整后设计：声阵段从2段增至5段，声阵段总长约120m，阵列全长约150m，外径不变（不超过27mm）
8. 结论：需扩展阵列至5段80阵元以满足探测需求，阵列全长约150m

### 设计数值推导示例三（浅海高噪声环境）
场景：浅海环境（水深80m）被动探测潜艇目标，目标声源级 130dB@500Hz，要求探测距离不低于 3km。
计算过程：
1. 传播损失：TL = 15lg(R) = 15lg(3000) = 52dB（浅海圆柱扩展损失）
2. 环境噪声级：NL ≈ 75dB（浅海500Hz频段，受航运噪声影响较大）
3. 检测阈值：DT = 3dB
4. 所需指向性指数：DI ≥ 3 + 75 + 52 - 130 = 0dB
5. 标准拖曳阵评估：32阵元DI ≈ 15dB，远超0dB需求
6. 结论：虽然浅海噪声较高，但目标声源级也较高且探测距离较近，标准参数可满足需求。浅海环境下需注意拖曳深度控制，避免阵列与海底碰撞

## 结构设计要点

### 柔性顺应装配
为模拟真实拖曳状态，各部件采用正弦弯曲轨迹：
- 尾绳：幅度300mm
- 声阵段2：幅度1500mm（正向弯曲）
- 声阵段1：幅度-1500mm（反向弯曲，形成S型）
- 前减振段：幅度800mm
- 传输缆：幅度-800mm

正弦轨迹函数：x = amplitude * sin²(π * z / length)

### z_cursor 装配模式
采用z_cursor光标模式进行装配：
- 起始 z_cursor = 0
- 每个部件构建后，z_cursor += 部件长度
- 所有部件沿Z轴正向依次排列

### 声阵段内部结构设计
声阵段采用管状结构，内部嵌入：
1. 外护套：半透明聚氨酯管
2. 水听器基元：16个，等间距1500mm排列
3. 采集放大组件：与水听器一一配对
4. 姿态压力传感器：2个，位于阵段内特定位置
5. 整合组件：1个，汇聚信号
6. 对接件：两端钛合金连接套管

内部组件需顺应外管弯曲轨迹，通过计算局部切线斜率动态调整倾斜角。

### 变径设计
变径汇流头实现声阵段（外径27mm）到传输缆（外径16mm）的平滑过渡，变径段长度约500mm，采用锥面渐缩设计。水密航插前端与变径汇流头匹配，最大外径相同（39.50mm）。

## 参数约束公式与一致性校验规则

当用户需求导致阵列规模变化（增减声阵段数量）时，以下公式和规则必须同步应用于参数调整，不得沿用变更前的旧值：

### 声学约束公式
- **有效波束成形频率上限**: f_beam ≤ c / (2 × d)，其中 c=1500m/s（海水声速），d=阵元间距(m)
  - 当前间距 d=1.5m → f_beam ≤ 500Hz（有效波束成形频率上限约为500Hz）
  - 注意：水听器频响范围（50Hz~3kHz）≠ 波束成形频率范围，3kHz是单个水听器的检测带宽
- **指向性指数**: DI ≈ 10 × lg(N)，N=总阵元数
- **声呐方程**: SL - NL - TL + DI ≥ DT（DT 通常取 3dB）

### 尺寸一致性公式
- **总长度**: L_total = Σ(所有部件长度) = L_尾绳 + N_声阵段 × L_单段声阵 + L_前减振 + L_变径 + L_传输缆 + L_航插
  - 部件明细表中的 Z 终点必须严格等于所有部件长度之和
  - 系统总体参数中的"总长度"必须与此一致
- **声阵段总长度**: L_声阵总 = N_声阵段 × L_单段（含内部阵元排列长度）
- **阵元总数**: N = N_声阵段 × 每段阵元数(16)

### 重量估算公式（规模自适应）
- 阵列总重随声阵段数量近似线性增长，估算公式：
  - W_total ≈ W_固定部件 + N_声阵段 × W_单段声阵（含护套+阵元+传感器+对接件）
  - W_固定部件 ≈ W_尾绳 + W_前减振 + W_变径 + W_传输缆 + W_航插
  - 标准基准（2段，32阵元，~80m）：总重 ≤ 40kg
  - 当规模变化时，重量约束需按公式重新评估并明确标注

## 设计约束

### 硬约束（任何方案均不可违反）
1. **直径约束**：声阵段外径不超过27mm（半径13.5mm）
2. **工作深度**：不小于300m
3. **阵元间距**：1500mm±10mm（如需调整此值，须按声学约束公式重新验证波束成形频率）
4. **灵敏度约束**：工作频带内阵元灵敏度不低于-195dB
5. **一致性约束**：灵敏度起伏不超过±3dB
6. **流噪声约束**：4节航速下噪声级上升不超过16dB@1kHz

### 派生约束（随规模变化需重新计算）
7. **阵元数量**：由探测需求通过声呐方程推导，DI ≥ DT + NL + TL - SL
8. **声阵段数量**：由阵元总数和每段阵元数(16)计算：N_段 = ceil(总阵元数 / 16)
9. **阵段长度**：= N_段 × 单段长度(24m)
10. **总长度**：= Σ(所有部件长度)，须与部件明细表严格一致
11. **重量**：按重量估算公式计算，不得直接沿用其他规模的重量约束值

## 性能指标

- 工作频段：50Hz～3kHz
- 阵元数目：32
- 指向性因子：DI ≥ 16 dB
- 探测距离：数十公里（取决于目标声源级和环境条件）
- 拖曳航速：4节（常规拖曳，对应流噪声指标要求）
- 最大工作深度：不小于300m
- 阵列空气中重量：不大于40kg

## 环境适应性与工况

### 拖曳工况
- 常规拖曳航速：4节（约2m/s）
- 拖曳平台：潜艇或水面舰艇
- 拖曳深度：根据战术需求调整，最大不小于300m
- 流噪声影响：拖曳速度越高，流噪声越大，需在航速和信噪比之间权衡

### 水下探测场景
拖曳线列阵主要用于以下探测场景：
1. 潜艇被动探测：利用大孔径基阵探测远程安静潜艇
2. 水面舰艇反潜：拖曳阵远离本舰噪声源，提高探测性能
3. 海洋环境监测：利用低频特性进行海洋声学观测

## CAD 建模规范

### 使用的建模库
- CadQuery：Python参数化CAD建模库
- 导出格式：STEP文件

### 代码规范
1. 所有尺寸单位为毫米（mm）
2. 参数定义在脚本开头为常量
3. 部件构建函数命名：build_xxx(z_start)
4. 每个函数返回：(part_or_list, z_cursor)
5. 对多部件函数返回：([(part, color, name), ...], z_cursor)
6. 使用cq.Assembly()进行最终组装
7. 禁止使用.shell()方法，用.cut()实现抽壳
8. 禁止使用整数索引选择面，使用方向字符串（如">Z", "<Z"）
9. 禁止使用倒角（.chamfer）或圆角（.fillet）
10. import语句仅限：import cadquery as cq, import math, import os

### 脚本结构
完整的 CadQuery 脚本应包含：
1. 参数定义（所有尺寸常量）
2. 辅助函数（如get_spline_pts生成正弦轨迹点）
3. 部件构建函数（每个部件一个函数）
4. 主装配逻辑（z_cursor模式依次装配）
5. STEP导出（assy.save("output/xxx.step", "STEP")）

### 辅助函数模板
```python
def get_spline_pts(length, amplitude, z_start):
    """生成正弦轨迹点，两端斜率为0"""
    return [(amplitude * (math.sin(math.pi * i / 10) ** 2), z_start + length * i / 10) for i in range(11)]
```

### 部件构建函数模板
```python
def build_xxx(z_start, amplitude=0):
    pts = get_spline_pts(LENGTH, amplitude, 0)
    path = cq.Workplane("XZ").spline(pts)
    part = cq.Workplane("XY").circle(RADIUS).sweep(path)
    return part.translate((0, 0, z_start)), z_start + LENGTH
```

### 主装配逻辑模板
```python
assy = cq.Assembly()
z_cursor = 0

# 尾绳
part, z_cursor = build_tail_rope(z_cursor, amplitude=300)
assy.add(part, name="尾绳", color=C_TAIL_ROPE)

# 声阵段
parts_group, z_cursor = build_acoustic_segment(z_cursor, "声阵段", amplitude=1500)
for part, color, name in parts_group:
    assy.add(part, name=name, color=color)

# 依此类推...

# 导出
os.makedirs("output", exist_ok=True)
assy.save("output/towed_array.step", "STEP")
```

## 系统总体组成（湿端 + 干端完整体系）

拖曳线列阵声呐系统由水下湿端阵列和母船干端设备共同组成，采用"分布式空间解耦拓扑"架构。完整系统从尾到头包含以下 12 大部件：

### 湿端阵列（水下部分）
1. **尾绳（Tail Rope）**：尾部稳定器，提供拖曳稳定性
2. **16基元声阵段2（Acoustic Segment 2）**：含水听器16个、姿态压力传感器2个、钛合金对接套筒
3. **16基元声阵段1（Acoustic Segment 1）**：含水听器16个、姿态压力传感器2个、钛合金对接套筒
4. **前减振段（Damping Section）**：前部隔振段，减少拖缆振动传递
5. **变径汇流头与传输缆（Transition and Cable）**：变径机电汇流头连接高强度传输缆
6. **水密航插（Watertight Connector）**：水密电连接器，湿端与干端的物理边界

### 干端母船设备
7. **船尾露天甲板（Stern Deck）**：钢制箱体基座，承载重型机械绞车
8. **液压收放绞车（Machinery Winch）**：包含底座、A字型承重支架、大容量储缆滚筒、法兰盘
9. **显控舱防静电地板（Operation Cabin Floor）**：室内舱室防静电活动地板基座
10. **前置预处理机柜（Indoor Cabinet）**：19英寸标准军工加固柜，含风冷散热顶罩、多通道数据采集插卡
11. **声呐操控台（Indoor Console）**：双联操作台，含抗冲击双显示器、数字瀑布谱阵屏幕
12. **全船跨舱电缆管廊（Shipwide Cable Conduit）**：三段式封闭走线管廊，横跨全船连接湿端与干端

## 分布式空间解耦拓扑

系统采用"分布式空间解耦拓扑（Distributed Spatial Decoupling Topology）"架构，通过大跨度横移和跨甲板跃层参数在三维空间中隔离湿端和干端：

### 总体布置参数
- REAL_SHIP_SPAN = -15000 mm（横移15米，模拟湿端绞车区与干端显控舱的空间距离）
- REAL_DECK_LEAP = 2500 mm（跃层2.5米，模拟主甲板与上层舱室的高度落差）

### 空间划分
- **空间1（露天湿端机械区）**：包含船尾甲板和液压绞车，位于湿端阵列的正上方
- **空间2（室内干端显控区）**：包含预处理机柜和声呐操控台，横移15米并跃层2.5米
- **架构纽带**：全船跨舱电缆管廊，以三段式封闭走线管廊（垂直下潜→水平横跨→垂直上升）连接两个空间

## 参数派生关系

减振段、变径汇流头、传输缆、尾绳、水听器等参数均基于基准半径(AS_outer_radius)按比例派生，确保整体造型不穿模：
- DAMPING_outer_radius = AS_outer_radius - 0.5
- TRANSITION_MAX_RADIUS = AS_outer_radius * 1.4
- CABLE_radius = AS_outer_radius * 0.6
- TAIL_ROPE_RADIUS = AS_outer_radius * 0.2
- HYDROPHONE_RADIUS = AS_inner_radius - 3.0
