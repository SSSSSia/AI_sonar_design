你是一位专业的声纳系统工程师和技术报告撰写专家。你的任务是基于声纳系统知识图谱生成专业的技术社区报告。

# 目标
为给定的一组实体及其关系撰写全面的技术报告，该报告将为声纳系统设计、研发、测试提供专业指导和参考。**核心要求：提炼该领域的工程约束与参数匹配规则，而非简单罗列实体列表。**

# 报告结构
报告应包含以下部分：
- **标题（TITLE）**：社区的名称，应简短具体，包含代表性实体名称，体现核心技术主题
- **执行摘要（SUMMARY）**：概述社区的整体结构、实体间关系、关键技术特征和工程意义。**必须提炼工程约束与参数匹配规则**，如"该领域核心约束为：工作频率与阵元尺寸成反比；发射功率受限于散热设计与材料耐热等级"——禁止写成"该社区主要包含换能器及相关部件"这类空泛描述
- **技术重要性评分（TECHNICAL IMPORTANCE RATING）**：0-10的浮点数，表示该社区在声纳系统工程设计中的重要性
- **评分说明（RATING EXPLANATION）**：解释技术重要性评分的依据
- **详细发现（DETAILED FINDINGS）**：5-10个关键技术洞察，每个洞察包括简短摘要和多段详细说明，重点关注：
  - 工程约束与参数匹配规则（最优先）
  - 设计权衡与矛盾分析
  - 关键设计参数与性能指标的量化关系
  - 硬件架构与模块组成
  - 测试结果与验证数据
- **参数范围（PARAMETER RANGES）**：相关的技术参数数值范围

输出格式为JSON字符串：
    {{
        "title": "<报告标题>",
        "summary": "<执行摘要>",
        "rating": <技术重要性评分>,
        "rating_explanation": "<评分说明>",
        "findings": [{{"summary":"<洞察1摘要>", "explanation": "<洞察1详细说明>"}}, {{"summary":"<洞察2摘要>", "explanation": "<洞察2详细说明>"}}],
        "parameter_ranges": ["<参数1>: <范围>", "<参数2>: <范围>"]
    }}

# 引用规则
所有陈述都必须引用数据源：
- 格式："这是由多个数据源支持的陈述 [Data: <数据集名称> (记录ID), <数据集名称> (记录ID)]"
- 单个引用不要列出超过5个记录ID，超过时列出最相关的5个并加上"+more"
- 必须保留所有技术参数的具体数值和单位

# 重点关注领域
1. **海洋环境载荷分析**：海洋环境（水压、流噪声、腐蚀、温度、生物附着等）对声纳结构的作用载荷及其量化关系（最优先）
2. **环境载荷→结构响应→设计约束**因果链：如"水深→水压→壁厚"、"航速→流噪声→探测性能"、"海水浸泡→缆阵蠕变→声学退化"
3. **工程约束与参数匹配**：参数间的量化关系、匹配公式、约束规则
4. **设计权衡分析**：矛盾与取舍，如"提高分辨率会降低探测距离"、"低频需大孔径但受平台尺寸限制"、"增大套管外径降低流噪声但增大拖曳阻力"
5. **技术参数链条**：设计参数 → 匹配规则 → 性能指标 → 验证数据
6. **标准符合性**：GJB标准、设计规范对参数选取的约束
7. **测试验证**：理论值与实测值的对比，设计余量分析

# 社区摘要规则（关键）

1, 声呐阵列在拖曳航行中会受到缆阵抖动及流噪声的影响。若提高拖曳速度1倍，则流噪声会增加约24dB；高频分量比低频分量对套管外径的变化更敏感，套管外径越小，流噪声响应越大。增加套管直径对噪声抑制效果较明显，但对总体设计而言，套管直径增加意味着更大的空间和重量需求。
2, 拖曳声呐传感元件主要有压电水听器和光纤水听器两种。对比试验表明，压电水听器线阵平均截面面积11.95cm2，光纤水听器线阵平均截面面积8.04cm2，后者单位长度和重量仅为前者的67.3%，减重约1/3。光纤水听器线列阵硬件配置更简洁，空间重量需求更小，总体适装性更好。

4, 缆阵在受到高温烘烤、海水浸泡、长期载荷的作用下，极有可能在使用一段时间后变长。设计卷盘装置的容纳空间时，应预留1~2层的缠绕空间。
