-Goal-
你是一位专业的拖曳线列阵声呐 CAD 建模工程师和知识图谱构建专家。给定一份拖曳线列阵声呐 CAD 建模相关的技术文档，请识别所有实体及其关系。核心目标是提取**部件结构与尺寸参数**、**设计约束与性能指标**、**CAD建模规则与装配逻辑**之间的关联关系，为自动化 CAD 建模提供知识支撑。

-Entity Types-
### 系统级
1. SonarSystem（声呐系统）: 拖曳线列阵声呐整机系统，如"拖曳线列阵声呐"、"Towed Array Sonar"

### 结构/模块级
2. StructuralModule（结构模块）: 拖线阵的六大组成部件，如"尾绳"、"声阵段"、"前减振段"、"变径汇流头"、"传输缆"、"水密航插"
3. Component（基础零件/器件）: 模块内部的元器件，如"水听器"、"姿态压力传感器"、"采集放大组件"、"整合组件"、"对接件"、"外护套"

### 参数/指标级
4. DesignParameter（设计参数）: 可量化参数，如"阵列直径27mm"、"阵元间距1500mm"、"尾绳长度10000mm"、"外护套壁厚3mm"、"正弦弯曲幅度"
5. PerformanceIndicator（性能指标）: 结果指标，如"阵元灵敏度-195dB"、"流噪声级16dB@1kHz"、"指向性因子DI≥16dB"、"探测距离数十公里"
6. DesignConstraint（设计约束）: 工程约束规则，如"阵列直径不超过27mm"、"空气中重量不大于40kg"、"最大工作深度不小于300m"、"灵敏度起伏不超过±3dB"

### 算法/规则级
7. Algorithm（算法/公式）: 计算公式和设计原理，如"声呐方程SL-NL-TL+DI≥DT"、"传播损失TL≈20lgR"、"正弦轨迹函数x=A*sin²(πz/L)"
8. CADModelingStandard（CAD建模规范）: CadQuery建模规则，如"函数命名build_xxx(z_start)"、"z_cursor装配模式"、"禁用.shell()方法"

-Extraction Guidelines-
1. 提取具体数值、单位、公差（如"直径不超过27mm"、"间距1.5m±10mm"）
2. 提取公式时保留完整表达式、变量含义
3. 重点提取部件之间的装配关系（从尾到头的顺序、变径过渡、段间连接）
4. 提取内部组件与外管的结构关系（水听器嵌于管内、间距排列、顺应弯曲）
5. 提取CAD建模规则时保留完整代码约束（禁用方法、命名规范、装配模式）
6. 提取颜色参数时保留RGB/RGBA值
7. 关系类型优先级：
   - 遇到"由...组成"、"包含" → consists_of
   - 遇到部件的尺寸、参数描述 → has_parameter
   - 遇到"不超过"、"不大于"、"不小于" → constrained_by
   - 遇到参数间的计算、匹配逻辑 → matches_with
   - 遇到"满足"、"为实现" → satisfies_requirement
   - 遇到设计权衡、矛盾 → trades_off_with
   - 遇到CAD代码规范 → modeled_by

-Steps-
1. Identify all entities. For each identified entity, extract the following information:
- entity_name: Name of the entity
- entity_type: One of the following types: [{entity_types}]
- entity_description: Comprehensive description of the entity's attributes, parameters and functions
Format each entity as ("entity"<|><entity_name><|><entity_type><|><entity_description>)

2. From the entities identified in step 1, identify all pairs of (source_entity, target_entity) that are *clearly related* to each other.
For each pair of related entities, extract the following information:
- source_entity: name of the source entity, as identified in step 1
- target_entity: name of the target entity, as identified in step 1
- relationship_description: detailed description of the relationship with technical details and parameter values
- relationship_type: one of: consists_of, is_part_of, has_parameter, derived_from, constrained_by, matches_with, satisfies_requirement, trades_off_with, modeled_by
Format each relationship as ("relationship"<|><source_entity><|><target_entity><|><relationship_description><|><relationship_type>)

3. Return output in Chinese as a single list of all the entities and relationships identified in steps 1 and 2. Use **##** as the list delimiter.

4. When finished, output <|COMPLETE|>
