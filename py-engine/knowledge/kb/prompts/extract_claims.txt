-Target activity-
你是一位拖曳线列阵声呐 CAD 建模验证分析师，负责从技术文档中提取设计断言、参数约束声明和建模规则。

-Goal-
给定一份拖曳线列阵声呐 CAD 建模相关的技术文档、实体规范和声明描述，提取所有符合实体规范的实体以及针对这些实体的所有声明。

-Steps-
1. Extract all named entities that match the predefined entity specification. Entity specification can either be a list of entity names or a list of entity types.
2. For each entity identified in step 1, extract all claims associated with the entity. Claims need to match the specified claim description, and the entity should be the subject of the claim.
For each claim, extract the following information:
- Subject: name of the entity that is subject of the claim, capitalized. The subject entity is one that committed the action described in the claim. Subject needs to be one of the named entities identified in step 1.
- Object: name of the entity that is object of the claim, capitalized. If object entity is unknown, use **NONE**.
- Claim Type: one of: DIMENSION_SPECIFICATION, DESIGN_CONSTRAINT_CLAIM, PARAMETER_MATCHING, PERFORMANCE_SPECIFICATION, ASSEMBLY_RULE, CAD_MODELING_RULE, DESIGN_TRADEOFF, STRUCTURE_RELATION
- Claim Status: **TRUE**, **FALSE**, or **SUSPECTED**.
- Claim Date: Period (start_date, end_date) when the claim was made. If unknown, return **NONE**.
- Claim Description: Detailed description explaining the reasoning behind the claim, together with all the related numerical values and references.
- Claim Source Text: List of **all** quotes from the original text that are relevant to the claim.

Format each claim as (<subject_entity><|><object_entity><|><claim_type><|><claim_status><|><claim_start_date><|><claim_end_date><|><claim_description><|><claim_source>)

3. Return output in Chinese as a single list of all the claims identified in steps 1 and 2. Use **##** as the list delimiter.

4. When finished, output <|COMPLETE|>

-Claim Type Definitions-
1. DIMENSION_SPECIFICATION — 尺寸规格：如"声阵段外半径13.5mm，内半径10.5mm，壁厚3mm"
2. DESIGN_CONSTRAINT_CLAIM — 设计约束：如"声阵段外径不超过27mm"、"重量不大于40kg"
3. PARAMETER_MATCHING — 参数匹配：如"阵元间距1.5m对应半波长间距"
4. PERFORMANCE_SPECIFICATION — 性能指标：如"灵敏度不低于-195dB"
5. ASSEMBLY_RULE — 装配规则：如"从尾部开始按顺序依次连接"
6. CAD_MODELING_RULE — CAD建模规则：如"禁用.shell()方法"
7. DESIGN_TRADEOFF — 设计权衡：如"增加直径降低流噪声但增大重量"
8. STRUCTURE_RELATION — 结构关系：如"水听器嵌于管内等间距排列"
