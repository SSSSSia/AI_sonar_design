# SonarCADLink · FreeCAD 交互微调插件

智能辅助声呐装备设计系统的 FreeCAD 端（PHASE-008，ADR-004）：登录平台 → 拉取 A3 生成
的三维模型 → 在 FreeCAD 内对话微调 → 定稿回传平台（IR3 版本链 + 审阅关②）。

自研 CadAgent 插件（`D:\Download\FreeCAD\Mod\CadAgent`，只读参考）迁移改造：
复用 CQ 翻译层/质量门禁/几何分析/渲染器，废弃本地 LLM 直连与会话落盘——
大脑在平台后端（py-engine `cad_agent`），插件是无状态执行器 + 聊天面板。

## 安装（FreeCAD ≥ 1.0）

1. 把 `SonarCADLink/` 整个目录复制进 FreeCAD 的 Mod 目录
   （Windows：`%APPDATA%/FreeCAD/Mod/`，或安装目录 `Mod/`）；
2. 重启 FreeCAD，工作台切换到 **SonarCADLink**；
3. 点工具栏「打开微调面板」。

零第三方 pip 依赖（标准库 urllib）；**零凭据**：插件不保存/不读取任何 LLM API key，
只用平台账号登录换 JWT（密码不落盘）。

## 使用流程

1. **登录**：填平台地址（默认 `http://127.0.0.1:8080`）+ 平台账号；
2. **选会话**：登录后面板自动列出**可微调的设计会话**（已推进到审阅关②暂停、
   或已有进行中的微调会话），下拉选中 → 「打开/新建微调」即可，无需复制粘贴 ID
   （列表可「刷新」；边缘情况可点「手输 ID」粘贴会话 ID）；
3. **拉取模型**：下载当前版本 STEP 导入 FreeCAD 视口；
4. **对话微调**：可在 3D 视图点选几何（会作为上下文上传），输入自然语言 →
   服务端 LLM 循环生成编辑代码 → 视口实时变化 → 收敛后自动上传新版本
   （平台三维预览按版本自动刷新）；
5. **定稿**：满意后点「定稿」→ 审阅关②审阅最新版本。

## 真机人工验收清单

| # | 步骤 | 预期 |
|---|---|---|
| 1 | 复制插件 → 重启 FreeCAD → 切工作台 → 打开面板 | 面板出现，显示"未登录" |
| 2 | 填错密码登录 | 报"登录失败：..."（服务端中文透因），不崩溃 |
| 3 | 正确登录 → 观察会话下拉框 | 自动列出可微调会话（项目/标题+状态+短 ID）；无可微调会话时显示提示文案 |
| 4 | 选无 IR3 的会话（或手输其 ID）→ 打开 | 报"IR3 尚未生成"类错误 |
| 5 | 下拉选 A3 完成的会话 → 打开/新建微调 | 提示创建成功（含基线版本号） |
| 6 | 拉取模型 | 新文档 SonarModel 出现模型；面板提示 STEP 无参数历史 |
| 7 | 点选一个面 → 输入"在这个面上加 4 个 M5 孔阵，间距 20mm" | 视口模型更新；面板逐条显示编辑代码质量；收敛后显示"已上传 IR3 v{n+1}" |
| 8 | 平台前端会话页三维页签 | 预览自动刷新为新版本（WS `cad_tune_updated`） |
| 9 | 问"当前模型总长多少？"（不改模型） | 直接文字回答，无新版本产生 |
| 10 | 故意输入模糊指令让代码失败 → 观察 | 面板显示质量门禁/错误透因，Agent 自动重试；不伪造成功 |
| 11 | 「停止」按钮 | 当前工具完成后中断后续执行 |
| 12 | 「恢复最近快照」 | 文档回到最近一次编辑前 |
| 13 | 关闭 FreeCAD → 重开 → 登录 → 打开同一会话 → 拉取模型 | 拿到的是平台最新版本（平台版本链=持久化，本地不丢） |
| 14 | 定稿 → 平台审阅关②裁决 | 审阅页可见最新版本特征/校验报告；批准后 ir_snapshot_id=最新版本 |

## 已知局限（诚实标注，A-16）

- **STEP 导入丢参数化历史**：微调以形体级布尔编辑为主（改尺寸=重新布尔）；
  参数化特征树编辑在二期路线（ADR-004 §4）。
- **主线程执行无强制超时**：恶性脚本可能卡住 FreeCAD 界面；缓解=语法预检 +
  「停止」按钮 + 服务端 180s 工具超时兜底。
- **定稿上传在主线程同步执行**：大模型（几十 MB STEP）上传期间界面短暂无响应。

## 目录结构

| 文件 | 职责 | 来源 |
|---|---|---|
| `Init.py` / `InitGui.py` | Mod 入口与工作台注册 | 新写 |
| `platform_client.py` | 平台 HTTP 客户端（登录/会话列表/长轮询/上传） | 新写 |
| `executor.py` | execute_edit_code 执行器（语法预检/沙箱/质量门禁/结构化回传） | 改编自 CadAgent tools.py |
| `snapshot_lite.py` | 单槽位执行前快照（安全网；版本链在平台） | 新写 |
| `panel.py` | 后端大脑模式聊天面板（长轮询 worker + 轮询渲染） | 改编自 CadAgent ui/* |
| `cq.py` / `cad_helpers.py` | CQ 风格 API → FreeCAD Part 翻译层 | CadAgent 原样迁移 |
| `quality.py` / `code_fixes.py` / `geometry_analyzer.py` / `doc_analyzer.py` | 质量门禁 / 错误提示 / 几何分析 | CadAgent 原样迁移 |
| `chat_renderer.py` / `theme.py` / `text_utils.py` | Markdown 渲染 / 主题 / 文本清洗 | CadAgent 原样迁移 |

协议单测在仓库 `clients/freecad-plugin/tests/`（无 FreeCAD 环境可跑：仅覆盖
platform_client 与消息整形；FreeCAD 相关代码走上面的人工验收清单）。
