## 阅读顺序建议

1. **写申报书 / 论文**：直接用三份定稿；《申报与论文写作指引》的出处索引负责把每一节指回定稿章节与代码位置；
2. **理解设计初衷与完整叙事**：《总体设计方案》（阅读时对照其附录 E 差异表——三道审阅关、检索五级链等以 E 为准）；
3. **查设计 ↔ 实现逐项对照**：`docs/设计实现对照与优化路线.md`（GAP-001）；
4. **查进度与运行态**：`docs/roadmap.md`（唯一进度事实源）、`docs/HANDOFF.md`（交接事实源）。

## 维护纪律

- 三份定稿修订：头部版本表登记 + devlog 记录，与相关改动同 commit；
- 《总体设计方案》正文一字不改，**仅附录 E.4 允许追加行**（实施现状流水，2026-09-30 起的既有纪律）；
- `archive/` 内容零改动（2026-10-08 经 `git mv` 迁移，历史可考）；
- 定稿口径随版本演进：重大版本（v0.x）收官时同步更新定稿头部的"口径基准"并复核关键数字；不更新则写作时须注明数字快照日期。
