# ADR-011: UI 风格基线切换深色科技风

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-10-10 |
| 触发 | 用户以早期纯前端原型 sonar-ai（D:\CODE_FILE\CODE_AI\sonar-ai）为视觉基准，要求全面参考其设计风格改版前端 |

## 决策

1. **风格基线变更**：由宪法 §7.3 原「浅色中性生产力美学（Zotero/Notion 式）」切换为「深色海洋科技风」，全面替换浅色基线，不做明暗双主题。宪法 §7.3 同步修订。
2. **色板 token（theme.css 与 docs/mockups/mockup.css 双侧同源，规则保留）**：
   - 背景：`--bg #070f1e`（内容区底）/ `--panel #0a1628`（侧栏面板）/ `--card #0f2035`（卡片浮层）/ `--bg-deep #060e1c`（更深层）
   - 交互 accent：`--accent #06b6d4`（cyan，可操作语义：按钮/链接/选中态）/ `--accent-2 #0ea5e9`（sky，与 cyan 组成 135° 渐变主按钮）
   - 语义色：`--ok #10b981` / `--warn #f59e0b` / `--err #ef4444` / `--info #8b5cf6`
   - 文字灰阶：`--text-1 #e2e8f0` / `--text-2 #cbd5e1` / `--text-3 #94a3b8` / `--text-4 #64748b`
   - 边框：低透明度青/白描边（`rgba(6,182,212,.08~.3)`、`rgba(255,255,255,.04~.08)`）
3. **装饰语言边界**：允许限定范围的霓虹光晕（boxShadow `0 0 20px rgba(6,182,212,.3~.4)`，仅用于品牌标、主按钮、进度条、运行中状态点）、网格纹理（仅欢迎横幅）、毛玻璃顶栏（`rgba(7,15,30,.9)` + blur）；交互语义仍由 accent 青色承担，语义四色不用于装饰。
4. **诚实交代不变（宪法 A-16）**：仅借鉴原型的布局、信息密度、图表与徽章语言，不引入其 mock 假数据；所有图表/徽章/状态必须由真实后端数据驱动，无数据支撑的功能不落地。
5. **图表库补齐既定选型**：宪法 D-02 既定 ECharts，本轮安装 echarts（按需注册 + 手动分包），属补齐选型而非新增选型，无需替代性 ADR。
6. **后续拟采用清单**（本轮不做，缺真实数据或需后端能力，待后端就绪后另立任务）：需求对话式解析（需对话 agent）、知识检索相关度百分比徽章（knowledge_ref 暂无 score 字段）、图纸资产库独立页（需聚合 API）、问题 AI 修复建议（需后端支持）。

## 后果

浅色样式代码路径全部移除（无双主题维护成本）；docs/mockups/ 九页同批深色化作为视觉基线存档；D3 图谱与 R3F 三维画布需逐处深色调色；既有测试中断言浅色样式的需同步修正。原型中「AI 能力评估雷达图」类无数据支撑的展示不迁移。
