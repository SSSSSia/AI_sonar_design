# ADR-012: 深色改版重启——分层小步实施方案（UI-2）

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-10-10 |
| 触发 | UI-1 深色改版（ADR-011）当日被用户裁决回档（7e9d684）后，用户主动要求重启："制定一个分层小步走的详细开发计划，不只是样式，要把已经实现的功能完美地迁移到那种风格展示上去" |
| 与 ADR-011 关系 | 恢复 ADR-011 的深色海洋科技风方向与全量色板定义；**取代其一次性整批实施方式**。ADR-011 的"已回档"状态保留作历史，其 mockup 深色稿（05cc24f）取回作视觉基线 |

## 决策

1. **方向**：前端整体迁移至深色海洋科技风（深蓝三层底 #070f1e/#0a1628/#0f2035 + 青色交互 accent #06b6d4/#0ea5e9 + 限定范围霓虹光晕/网格纹理/毛玻璃顶栏），色板 token 沿用 ADR-011 定义，交互 accent 统一命名 `--accent` 系（theme.css 与 mockup.css 双侧同源）。
2. **实施方式 = 分层小步（L0-L4，约 17-20 提交，三确认关卡）**，四条红线入宪（v1.6 §7.3）：
   - ① 功能零回归：不动 api/stores/hooks/路由/数据流，风格化展示一律叠加；
   - ② 一步一提交：build + vitest + 页面走查全绿才前进，每步可独立 revert；
   - ③ 新依赖单独成步并显式提示 npm install（echarts 为唯一依赖步）；
   - ④ 每层结束跑 `docs/ui2/功能走查清单.md` 并留档。
3. **功能迁移原则**：已有功能逐项映射到新风格展示形态（光斑统计卡/发光进度条/状态胶囊/图表化等），映射表见 roadmap UI-2 与本 ADR 附表；所有展示数据来自真实接口聚合（A-16），原型中缺后端支撑的创意（对话式解析/相关度徽章/图纸资产库/AI 修复建议）继续不做、沿用 ADR-011 拟采用清单。
4. **素材复用**：UI-1 各提交（除文档类）基于当前浅色基线可 `git show <sha> -- <paths> | git apply` 分组重放——c7f34ae（后端 llm 通路）、5d4a322（主题）、c8f1e34（壳层+胶囊）、400ea8c+ed8f2f2（仪表盘图表+弧段修复合并）、a0d35ca（报告图）、b8a6465（项目卡）、df6560c（16 文件清扫，L2 主体素材）、05cc24f（mockup 基线）。

## 附表：已有功能 → 深色展示迁移（摘要，完整落点见 roadmap UI-2）

登录页声呐纹样青霓虹化；侧栏渐变+顶栏毛玻璃+SonarMark 霓虹；通知未读行/未读点深色化；仪表盘五格统计升级光斑卡+新增欢迎横幅/近 7 天趋势/状态环形图（会话表、筛选、批量删、项目过滤、WS 实时进度全部保留）；管线时间线青/琥珀/红语义映射；审阅参数深色表格+gate 裁决卡强调；校验报告保留清单+新增 IR4 四级分布横条图；三维预览深底画布+深色 gridHelper；知识库文档池/抽取/三库/供应商深色表格与表单；知识图谱 D3 深底亮色系+hover 发光；项目卡五态统计格+完成度发光进度条；系统管理状态点语义保留；顶栏新增 LLM 供应商状态胶囊（后端 /api/v1/llm 通路，网关镜像重建为生效前提，此前如实灰态）。

## 验收与回退

- 每步 DoD：`npm run build`（tsc）+ vitest 43 用例 + 受影响页面浏览器实操 + 截图（会话内留档）。
- 每层轻量 tag `ui2-L0…ui2-L4`；任何一步 `git revert <sha>` 独立回退。
- 关卡①L1 完（骨架变深）、关卡②L2 完（全站协调+visual-judge 全页）、关卡③L3 完（功能增强逐项走查）；L4 收尾全量回归+正式验收。
