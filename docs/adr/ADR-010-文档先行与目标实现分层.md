# ADR-010: 文档先行与目标、实现分层

| 项 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-10-09 |
| 触发 | 用户明确允许文档方案先行，代码后续逐步实现，以支持报告与论文设计章节 |

## 决策

1. 完整总体设计方案作为目标方案主稿，可先定义尚未实现的架构与技术机制；采用“拟采用、设计为、应支持”等设计表述，不受当前实现完整度限制。
2. 架构定稿、技术定稿中的实现事实、实现一致性核查与历史测试记录继续如实保留。文档先行不将未实现目标改记为完成，不改软件版本或 roadmap 完成状态。
3. 报告/论文的需求、总体设计、技术路线章节讲完整目标；系统实现与实验验证章节仅描述已实现、已测试的范围。阶段性区别用集中说明与对应章节边界表达，避免目标方案被实现清单割裂。
4. README 与写作指引提供目标方案审阅和当前实现核对两条阅读路径；完整方案顶部明确目标身份。后续代码工作以设计需求与差异清单衔接，本轮不启动代码修改。

## 后果

可先与老师讨论完整方案，再分阶段补代码。归档原稿、原图和前快照不变；ADR-009 的事实发现继续有效，不能将新目标或示例段落作为验收证据。
