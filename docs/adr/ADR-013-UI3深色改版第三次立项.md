## 决策

1. **方向与设计语言**：全面深色单主题，视觉基准 = sonar-ai 原型实物。核心语言：app 底 `#070f1e` / 卡片 `#0a1628` / 浮层 `#0f2035` 三层深海军蓝；交互 accent 青 `#06b6d4`（CTA 渐变 `#0ea5e9→#06b6d4` + 限定光晕）；状态色 tinted 徽章范式（rgba 底+同色边+同色字）；可折叠侧栏 240↔72px；中文主标签+英文副标签；发光进度条/统计卡光斑。token 落 `frontend/src/styles/theme.css`（`--accent` 系命名沿用 ADR-012 约定，与 mockup.css 同源），AntD darkAlgorithm 同步。**本期只做深色**；token 层按可扩展双主题结构组织但不实现浅色分支。
2. **流程三关卡**（吸收 UI-1/UI-2 全部教训）：
   - **关卡A 阶段0 基线核验（✅ 2026-10-10 已过）**：四套测试全绿（py 435+8skip / Java 86 / vitest 43 / 插件 18）+ 浏览器真实栈 12 项固定路径走查 + 存量缺陷清零。**固定走查路径 = 此后每个实施步骤的回归对照**。
   - **关卡B mockup 逐页确认（宪法 §7.3 硬前置）**：以 git 历史深色稿（05cc24f / 29884c2）为底，逐页对照 sonar-ai 实物校准风格；补齐 sonar-ai 没有的页面（登录、会话工作台四 Tab、admin）同语言衍生；**页面内容以本项目真实功能为准**（展示真实页面结构，不照搬 sonar-ai 假页面）。用户逐页确认全部定稿后才进入代码，代码零投入前锁定方向。
   - **关卡C 分支实施 + 总验收**：`feature/ui3-dark` 分支小步提交，每步 = 独立 commit + `npm run build` + vitest 绿 + **浏览器真实栈复走阶段 0 固定路径**；全站风格一致 + 四套测试 + 全链路复走 + 逐页对 mockup 核对后才合回 main 并 tag v0.8.0。**用户只在最终一致态验收，main 全程不暴露中间态。**
3. **功能零回归机制（第一红线）**：①每步真实栈复走（不只 build/单测）；②依赖步显式 `npm install` + dev 挂载冒烟通过才继续（UI-1 疑似根因）；③触碰后端（LLM 胶囊、kb/search）按 HANDOFF 纪律重启 uvicorn + celery worker + 对应 jar；④Java 侧改动一律 `mvn clean package -pl <模块>`（过期增量编译陷阱，见 HANDOFF 2026-10-10 条目）；⑤任何功能异常**立即停下**：修复复验或 revert 该步，不带病推进。
4. **依赖**：echarts 6（宪法 D-02 技术栈锁定图表库），独立依赖步；按需封装与 vendor-echarts 分包从 git 历史（b7ed1a9）取回适配。
5. **功能增强范围（阶段3，全部接真实后端，A-16 诚实原则）**：
   - 知识检索 Tab：py-engine kb 路由新增 `POST /api/v1/kb/search`（包装现有三级降级检索 service，返回命中+来源+位置+命中层级，降级轨迹如实展示）；网关 `/api/v1/kb/**` 已路由无需改；前端 KB 页新增检索 Tab（相关度排序命中卡片）。
   - 仪表盘增强：Agent 执行日志面板（logs API+WS 已有）、活动趋势图真实数据（会话/任务统计，如需聚合端点小步加）、系统状态盒（真实健康端点）。
   - 一致性检查交互化：IR4 报告重构为风险汇总卡（可点筛选）+ 问题卡片列表 + 详情抽屉 + 问题类型分布图——纯前端重构已有真实数据。
   - **排除**：AI 能力评估雷达图（sonar-ai 中为虚构自评数据）、一切假统计/假上传/假生成动画；"AI 修复建议"需新 LLM 能力，不放假按钮。
   - **后续立项**（本期不做）：对话式需求解析（A1 对话层端点 + chat UI）、项目字段增强（priority/截止日，需 Flyway 迁移）、视觉元数据资产库（MinIO+新表）。sonar-ai「基础元数据」页经阶段 0 核实已由现状覆盖（元数据管理 + LLM 供应商 Tab，T13.7），无需重复建设。
6. **素材复用**：UI-1 功能提交可 `git show <sha> -- <paths> | git apply` 分组重放（c7f34ae 后端 llm 通路 / 5d4a322 主题 / c8f1e34 壳层+胶囊 / 400ea8c+ed8f2f2 仪表盘图表 / a0d35ca 报告图 / b8a6465 项目卡 / df6560c 清扫）；UI-2 骨架（4b25568..862c00f）、深色 mockup（29884c2）、走查清单（4b25568）。

## 验收与回退

- 分支每步 DoD：`npm run build`（tsc）+ vitest 43 + 受影响页真实栈走查。
- 总验收（合 main 前）：四套测试全绿 + 阶段 0 同路径全链路复走 + 逐页视觉核对 mockup + 走查清单留档。
- 回退：main 合入前全程不动（可运行性零威胁）；分支任何一步可独立 `git revert`；整分支可放弃，main 零污染。合入后如需回退走整分支 revert（单提交合并）或 git revert 系列。
