# Sonar-CAD 用户指南（v0.6）

> 面向最终用户的按角色操作手册（PHASE-012 T12.9，M5「培训」交付物）。
> 配套：[vLLM 切换手册](vLLM切换手册.md)（管理员）、[deploy/backup/README](../../deploy/backup/README.md)（运维）。
> 走查自检：PHASE-011 §5 附录 A 自检⑤的补走查清单与本指南章节一一对应。

## 0. 角色与入口

| 角色 | 能做什么 | 入口 |
|---|---|---|
| **设计人员**（designer） | 建项目/会话、发起设计、审阅页查看与修订需求、CAD 微调、正向改参数、导出文档 | 浏览器打开平台首页 |
| **审阅者**（reviewer） | 设计人员全部只读能力 + **审阅关①②裁决**（批准/驳回） | 同上 |
| **管理员**（admin） | 全部能力 + 用户管理、军标/公式/约束三库管理、LLM 供应商管理、日志中心、备份恢复 | 同上 + 「系统」菜单 |
| **只读**（viewer） | 全部页面可查看，不可写 | 同上 |

登录：管理员发放账号（默认种子账号见 HANDOFF，**上线必改**）→ 输入用户名密码 → 顶栏显示角色标签。忘记密码找管理员重置。

## 1. 设计人员：从需求到三维模型

1. **建项目**：左侧「项目管理」→ 新建（名称/编号/描述）。
2. **建会话**：仪表盘「新建会话」抽屉 → 选项目 → **选知识库**（不选=Agent 自主圈定）→ 输入自然语言需求（如「设计 24 阵元拖曳声呐基段，工作深度 300m」）→ 提交。
3. **看进度**：会话总览实时显示 A1 需求解析 → A2 方案 → **审阅关①** → A3 建模 → A4 校验 → **审阅关②** → A5 知识沉淀；每步日志在「全部日志」抽屉可回看。
4. **修订需求（人工核对）**：审阅关①暂停时，「IR1 需求解析」卡点「修订需求（人工核对）」→ 逐行改目标维度/取值、增删缺失项 → 提交后重算 A2（解析原文不会重跑）。修订的目标标记为「显式」。
5. **CAD 微调（FreeCAD 插件）**：A3 完成后，在 FreeCAD 内安装 SonarCADLink 插件 → 登录平台 → 拉取当前模型 → 点选+自然语言微调 → 每轮上传真实 STEP 自动实测几何 → 定稿后进入审阅关②。13 步真机清单见 `clients/freecad-plugin/README.md`。

## 2. E1 参数双向联动（v0.4/v0.5 新能力）

两个方向都**必经人工确认/审阅关②复审**，不会静默改设计：

- **CAD → 文档（反向回写，v0.4）**：微调定稿后，实测几何与登记参数有偏差时，「审阅与参数」页签出现**参数变更提案卡**（旧值/实测值/偏差%）→ 逐条「应用」或「忽略」，或「全部应用」→ 应用后 IR2 追加新版本、校验报告重算、回到审阅关②复审。
- **文档 → CAD（正向联动，v0.5）**：审阅关②暂停时，「IR2 参数方案表」卡点「修改参数（E1 正向）」→ 选参数、填新值与理由 → 提交后 CAD **按新参数重新建模**（A3 重算，通常数分钟），完成后自动回审阅关②复审。
- **变更抑制**：连锁参数变更有传播深度上限（3）——达到上限时平台要求走审阅关驳回返工或人工重新建模，防止改参↔改模循环震荡。

## 3. 审阅者：裁决

1. 审阅关①（IR2 参数方案）/ ②（IR3 模型 + IR4 校验报告）暂停时，审阅页底部「裁决」面板可用。
2. **批准**：直接提交（gate1 空方案会二次确认）。
3. **驳回**：必须填批注 + 选回退目标（gate1 可回 A1/A2；gate2 可回 A2/A3，IR4 的回退建议会标注）→ 提交后下游产物失效并局部重算。
4. **校验报告**：看 IR4 总体结论、**CSR 约束满足率**（公式复算/军标核对/几何数值复核的通过率，tooltip 有口径）、逐条问题（错误/警告/提示三级，错误必须处理）。
5. **知识关**：会话完成后裁决知识沉淀候选入库与否（可选手目标知识库）。

## 4. 管理员

- **用户管理**：系统页「用户与角色管理」→ 新建（用户名 3-32 位字母数字、初始密码≥6 位、角色多选）/ 角色分配 / 启停 / 重置密码 / 删除。护栏：不能停用或删除自己；不能动掉最后一个启用的 admin。
- **三库管理**：知识库页「公式/约束/军标」页签逐条 CRUD；**军标批量导入**：军标页签「批量导入」→ 上传 xlsx/csv（列头=字段名：code/name/applies_to/requirement/expr/confidence/enabled）→ 预览校验 → 确认入库。按编号 upsert（已存在则更新）。真实 GJB 文本到位后由此入口规模化录入。
- **LLM 供应商**：知识库页「供应商」页签（admin）——新增/启停/优先级（越大越优先）；失败自动转移次选。私有化 vLLM 接入见 [vLLM切换手册](vLLM切换手册.md)。出站内容自动脱敏（密钥/密码等）。
- **日志中心**：系统页「日志中心」→ 按会话 ID 前缀/级别/关键字跨会话检索运行遥测。
- **备份恢复**：`deploy/backup/backup.sh`（每日定时建议）+ `restore.sh --drill` 演练；见 [deploy/backup/README](../../deploy/backup/README.md)。
- **监控**：Grafana（容器部署 :3300）看平台总览与 Agent 管线面板；5 条核心告警（Agent 超时/CadQuery 失败率/检索 P95/队列积压/缓存命中率）经 Alertmanager 推送通知中心。
- **审计中心（v0.6）**：系统页「审计中心」→ 按操作者/动作/资源类型/时间窗检索审计留痕。留痕范围（§9.4 口径）：登录/用户管理/项目与会话写操作/审阅裁决/知识库写/导出——Agent 调用、参数变更、知识回写由溯源体系专表承担（会话「执行记录」与 IR 版本链查看）。
- **元数据管理（v0.6）**：知识库页「元数据管理」页签（写仅 admin）——声呐类型（安装形式×功能体制双维度）/ 频率段定义 / 性能参数规范 / 提示词模板（版本化：同环节同名重复创建自动递增版本；启用某版本自动停用同键其他版本）。种子数据来自总体设计附录 D（示例口径）。

## 5. 项目成员与数据可见性（v0.6）

- **项目卡「更多 → 成员管理」**（项目负责者或管理员）：按用户名添加成员 / 移除成员；负责人（owner）行随项目存在不可移除。
- **可见性口径（§9.4 项目级）**：项目负责人与成员可见本项目及其全部会话；非关联用户在项目列表/仪表盘中不可见（不暴露存在性）。非成员不能在项目下新建会话。
- 审阅裁决不受成员关系约束（仍按 reviewer/admin 角色）。

## 6. 通知中心

- 顶栏铃铛：**待裁决**（仅推送给 admin/reviewer）与**系统告警**实时弹出；通知已持久化到服务端——刷新/换设备登录后仍在。
- 待裁决项点击直达会话；管理动作（全部已读/清除已读/清空/单条删除）同步到服务端。

## 7. 交付物下载

- 会话「三维预览」页签：STEP 模型 / CadQuery 脚本 / IR 快照 JSON。
- 「校验报告」页签：**导出 Word / 导出 PDF**（军标格式：封面+设计文档+参数表+溯源依据+校验结论；内置模板，正式军标模板到位后可替换；PDF 经 gotenberg 容器转换，未部署时按钮提示 503 如实）。

## 8. 常见问题

| 现象 | 处置 |
|---|---|
| 阶段卡住不动 | 看会话「全部日志」；A2/A3 涉及真实 LLM 调用，单阶段数分钟属正常；异常可失败后「重新执行」 |
| 正向改参数后 3D 未变 | A3 重算需数分钟（LLM 重新建模）；完成后自动回审阅关② |
| 提示「已达最大传播深度」 | 连锁变更过长——走审阅关驳回返工或人工重新建模 |
| 429/请求过载 | 平台限流保护，稍候自动恢复（前端已带指数退避） |
| 检索结果不理想 | 确认知识库已选对；图谱级命中靠已确认抽取条目，先补知识 |
