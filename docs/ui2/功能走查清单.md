# UI-2 功能走查清单（宪法 v1.6 §7.3 红线④配套）

> 用途：深色分层改版（ADR-012）每层结束跑一遍并留档，作为"功能零回归"的正式证据链。
> 规则：破坏性动作（删除/批准/驳回/清空/强制）一律只打开确认框后点**取消**；上传类只打开对话框不真正上传。
> 记录方式：每层一行填入文末《留档表》，异常项写明现象与定位。
