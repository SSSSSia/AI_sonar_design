### 补充 1：T9.1 uvicorn「连接建立但无响应」挂死——根因定位与防御性修复 ✅（ZCode）

- 背景：2026-09-19 全站审查期间实发（HANDOFF 待决事项首位）——连接建立但无响应、堆积约 50 连接、重启恢复、根因未查。PHASE-009 首个任务。
- 探索事实（修正任务书假设）：py-engine `api/` 全部路由为同步 `def`（0 个 async），跑在 Starlette/AnyIO 默认 **40 线程**的线程池上——原假设「async 路由内混同步 IO」不成立，真实嫌疑是**线程池耗尽**。
- 根因结论（机制复现，A-16 如实口径）：`tests/load/hang_repro.py`（synthetic 模式：子进程加载真实 `api.main.app` + 注入慢同步端点与旧版同步 healthz 复刻）。实测（本机，100 并发 × 同步 sleep 10s）：
  - 40 线程档（修复前等效）：旧版同步 healthz 排队 **max 6.15s**（负载持续更久则随线程释放才返回，特征即「连接建立但无响应」）；新版 async healthz **0.00s**（池饱和时跳过 broker 探测，如实 degraded）；
  - 120 线程档（修复后默认）：两者均 ≤0.03s。
  - 判定：机制成立，与 2026-09-19 现场（前端轮询无退避持续放大）特征吻合；原始现场未在真实栈复放，此为等效机制复现。未涉及架构调整，不补 ADR。
- 修复内容：
  - `app_config.py`：新增 `API_THREAD_POOL_SIZE`（默认 120）/ `API_HEARTBEAT_STALE_S`（5）/ `UVICORN_TIMEOUT_KEEP_ALIVE_S`（30）；
  - `api/main.py`：lifespan 启动时把 AnyIO 线程池上限提到配置值 + 起事件循环心跳协程（每秒打点）；`/healthz` 改 async——心跳滞后超阈值 → 503（供容器探针/重启联动，探针永不排队：不占线程、池饱和时跳过 broker 探测如实标注）；
  - `api/cad_agent.py`：`poll_tool_calls` 长轮询 async 化（原每连接占线程池线程最长 25s，现挂事件循环，每 0.5s 借线程做一次快查）——首要嫌疑点；
  - `scripts/start-all.sh`：uvicorn 补 `--timeout-keep-alive`（env 可调）。

### 补充 2：T9.2 CSR 约束满足率落地 ✅（ZCode）

- 口径（写死于 `a4_validation/agent.py` run() 注释 + PHASE-009 §2.2 + 前端 tooltip，三处同文案）：CSR = 通过/(通过+违反)×100，两位小数；计数对象 = formula 复算、standard 符合性核对、CHK-GEO-NUM 几何数值复核（产出确定性判定的检查）；warning/info 不计分母；结构完整性错误（悬空引用/特征重复/产物缺失/退化）不计入（属产物完整性，由 overall=fail 体现）；无有效检查 → `csr=null`。
- 实现：A4 run() 穿统计器——复算一致/军标通过/数值容差内静默计 pass（不产 issue 保持低噪音），复算不符/军标违例/数值超差计 violation；`ir4.schema.json` 增可空 `csr`（0–100，additionalProperties:false 保留，旧快照双形态兼容）；ReportTab IR4 卡增 CSR 数值卡（null 显示「—」+ A-16 说明文案）+ 口径 tooltip。
- 验证：`test_t92_csr.py` 7 用例（100/50/33.33/warning 不稀释/几何计入/全 skip null/空参数 null）；契约测试新旧形态正反用例；A4 存量 44 测试全过；前端 tsc 0 错 + vitest 35 过；e2e（phase2）IR4 必带 csr 字段断言（T9.7 全量回归时统一跑）。
