### 补充 1：侧边栏固定视口 + 收缩态观感修复（用户反馈）✅（ZCode）

- 反馈（附截图）：①侧边栏收缩后，分组标题「工作台/知识/系统」以文字夹在图标中间很难看，底部 antd 默认触发条（细箭头）也不好看；②侧边栏没有固定——整页滚动时侧边栏跟着滚走，后面直接看不见了
- 根因：外层 `Layout` 是 `minHeight: 100vh` 随文档流滚动（Sider 无固定）；antd inline Menu 的 `type: 'group'` 分组标题在收缩态不会被隐藏；默认触发条样式突兀
- 实现（只动 `AppLayout.tsx` + `theme.css`）：
  - 外壳固定：外层 `Layout` 改 `height: 100vh; overflow: hidden`，内层（Header+Content）`overflowY: auto` 独立滚动——侧栏与顶栏常驻；`.app-sider .ant-layout-sider-children` 纵向 flex（theme.css），菜单区 `flex: 1` 超长自身滚动，底部按钮常驻
  - 收缩态菜单：平铺为纯图标（分组间插 divider 保留层级），antd 收缩态自动出悬浮名称提示；展开态保持分组标题不变
  - 底部按钮：`trigger={null}` 去掉 antd 默认触发条，自绘「收起侧栏 / 展开」文本按钮（borderTop 发丝线分隔）；窄屏（<xl）强制收缩时该按钮无效，随之隐藏
- 验证：tsc 0 错 + vitest 35 过；浏览器实机走查（admin 登录）——展开态正常；收起后分组文字消失、图标+分隔线、悬停出「系统管理」提示；会话详情页滚动到页面底部，侧栏与顶栏纹丝不动；再点「展开侧栏」完整还原

### 补充 3：知识关跳过不收敛 + 可重复点堆积裁决 + 「回写 [object Object]」三连修复（用户反馈，严重 bug）✅（ZCode）

- 现象：知识关点「全部跳过」只插一条裁决记录，IR5 永远 pending、面板永驻，可无限重复点击；批准批注显示「回写 [object Object]」
- 根因（Explore 定位）：①「跳过」没有终态——后端 reject 分支只插记录不迁状态，全系统唯一 pending 迁移在批准回写成功时；②知识关裁决无幂等校验（gate1/2 靠 paused@gate 前置 + 状态推进自然收敛，知识关 completed 后无此保护），insertRecord 无条件执行；③Java 把 py-engine 回写响应整个 Map 存进记录 autoFields + 前端 writebackText 只处理字符串形态
- 修复：
  - 语义补全：IR5 `writeback_status` 增加 **skipped 终态**（契约 schema、候选如实保留）；py-engine 新增 `POST /knowledge/writeback/skip`（pending→skipped，幂等；writeback 接受 pending|skipped 以支持「补做」）；phase-2 文档同步
  - Java：reject 分支改调 skip 客户端并加幂等校验（非 pending 重复跳过 409，不再堆记录）；approve 接受 skipped（补做）；回写结果改存摘要字符串 `writebackSummary()`（"已写入图谱（新增 N · 废弃 M · IR5 vK）"）
  - 前端：ReportTab 面板 pending|skipped 双态渲染（skipped 显示「已跳过，可批准补做」Alert、「全部跳过」按钮隐藏）；IR5 类型与 WRITEBACK_LABEL 加 skipped；writebackText 兼容对象形态（旧记录直接修好显示）
- 验证：py-engine t23 14 过（+skip 终态/幂等/补做用例）；Java workflow 34 过（+幂等 409/skipped 补做/摘要断言）；tsc 0 错 + vitest 35；py-engine 与 workflow 均重启；浏览器实机验证用户会话裁决历史——批准记录已正确显示「已写入图谱（新增 5 · 废弃 0 · IR5 v2）」
- 注：历史遗留的两条重复驳回记录如实保留（A-02 留痕不删）；跳过链路的端到端真机验收待用户下一个走到知识关的会话
