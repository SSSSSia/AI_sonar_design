# 本科毕业设计选题说明

## 面向设计文档生成的知识增强对话智能体设计与实现

## 1 课题目标

面向一种通用工程设计场景，开发具有知识库支持的多轮对话智能体。系统通过对话了解设计意图、追问缺失信息、讨论方案，最终生成有依据、可修改和导出的设计文档。具体场景可选择声呐设计领域，资料使用公开文档或自建样例。

## 2 主要工作

1. 建立设计知识库，支持技术资料检索和来源查看，为回答与方案建议提供依据。
2. 实现多轮对话，支持主动追问、补充与修改要求，并在条件冲突或资料不足时提示用户确认。
3. 管理上下文，区分已确认需求、待确认信息和知识建议，避免遗忘、重复提问及新旧要求混淆。
4. 实现 Web 界面，展示对话、需求状态、知识来源和设计文档草稿，支持查看与修改。
5. 根据确认后的需求和知识依据生成设计文档，包含设计目标、需求约束、总体方案、主要模块、选型依据及待确认事项，并支持导出。

## 3 研究重点

重点研究知识检索与对话的协同方式，以及多轮交互中的上下文管理。需要回答：何时检索、何时追问，如何利用检索证据补充方案依据，用户修改条件后如何保持对话与文档一致。

通过对照实验比较引用依据、澄清效果和文档完整性，并对上下文管理做适量分析。若采用图谱增强检索，可将普通向量 RAG 作为对照。

## 4 技术与范围

建议参考 Pi Agent 管理智能体与会话，参考 Microsoft GraphRAG 实现图谱增强检索。GraphRAG 结合实体关系与原文片段，选用时可先采用局部检索 Local Search。

## 5 开发方式与成果

交付可演示的系统、完整源码与运行说明、实验分析，以及系统实际生成的一份设计文档。建议前 2 周确定场景与方案，第 3 至 8 周完成原型，第 9 至 12 周完成实验、论文和演示。
