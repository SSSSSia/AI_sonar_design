## 1. P0 阻断（优先修）

### P0-1 校验报告页签：IR5 候选 relation 行裸吐整段 JSON
- **位置**：会话工作台 → 校验报告 → 「IR5 知识沉淀候选」表 · 内容列
- **现状**：内容列显示 `{"to":{"name":"每阵段阵元数","type":"DesignParameter"},"from":{"name":"声阵段",…},"relation":"CONTAINS",…}` 整段 JSON（实测「验收预跑B」5 条候选中 3 条如此）。知识审阅关（A-10）的裁决对象不可读，等于对 relation 类候选不可用。
- **根因**：`frontend/src/pages/session/ReportTab.tsx:170` 内容列取 `summary/description/name` 失败时兜底 `JSON.stringify(p)`。
- **类别**：【违 mockup 06】（内容列为「湿端直径 —影响→ 拖曳阻力」可读三元组）·【违宪法 A-16 精神】
- **建议**：relation 渲染 `A —关系→ B` 三元组 + context 作灰字副行；其余类型截断摘要；类型/去重枚举中文化（联动 P2-3）：

```
┌────────┬──────────────────────────────────┬──────────┐
│ 类型    │ 内容                              │ 去重      │
├────────┼──────────────────────────────────┼──────────┤
│ 关系    │ 声阵段 —包含→ 每阵段阵元数          │ 新增      │
│        │ └ 一个声阵段包含特定数量的阵元        │          │
│ 案例    │ 拖曳线列阵声呐（32 阵元）            │ 重复 82% │
└────────┴──────────────────────────────────┴──────────┘
```

### P0-2 接口失败/挂起被渲染成「暂无数据」空态，无任何错误反馈
- **位置**：知识库五页签全部列表 + 系统管理「服务可达性」py-engine 行；py-engine 挂死期间实测
- **现状**：列表查询失败/挂起时表格以空 dataSource 渲染默认「暂无数据」+ 半透明 spinner——用户看到「库里没东西」而非「服务不可用」。挂死期间文档库/三库/LLM 供应商/图谱全部「暂无数据」、图谱画布空白无 loading。`DocumentsTab` 对上传/删除有 `message.error`，唯独列表无 `isError` UI；探测走 axios 默认 30s 超时，「检测中…」长时间悬挂后翻「不可达」。
- **类别**：【违宪法 A-13/A-14 精神】（禁止静默失败 / 降级如实）
- **建议**：三态分明——加载中（spin 遮罩 + 「加载中」文案）、失败（红字 + 重试 + 「数据可能存在，仅暂时不可达」）、真空（业务化空态，见 P2-10）：

```
┌─────────────────────────────────────────────────┐
│ ⚠ 知识库服务不可达，无法获取文档列表                 │
│    GET /api/v1/kb/documents · 5s 前超时            │
│                              [重试] [查看服务健康]    │
└─────────────────────────────────────────────────┘
```
探测建议独立 axios 实例（timeout 5s）；失败行附降级影响说明（mockup 09 原意）。

### P0-3 降级会话带着「0 参数 IR2」到审阅关，裁决对象为空仍可批准
- **位置**：会话工作台 → 审阅与参数（实例：d50db0d5 gate2 待审、c4e54e0f A3 失败，均 IR2 = 0 项）
- **现状**：IR2 参数表「（0 项）」+ 默认「暂无数据」，无解释；裁决面板照常可批准。审阅人无从判断「A2 降级没参数」还是「数据丢了」，批准等于放行空方案进 A3（正是两个失败会话的成因链）。
- **类别**：【违宪法 A-11 审阅关语义 + A-16】
- **建议**：`params.length===0 且存在降级标记` 时空态改警示引导：「**IR2 无参数（A2 由降级流程生成）。建议驳回并回退 A2/A1，待 LLM 恢复后重算；不建议批准空方案进入建模。**」gate 横幅同步提示；批准按钮加二次确认。（devlog 补充 30 已修 ReviewTab 的红 Alert——本次走查该会话横幅已存在，但参数表空态本身仍是裸「暂无数据」，缺行动指引。）

## 2. P1 明显

### P1-1 IR2 参数表「出处/推导」列整段倾倒 LLM 原文且双段重复
- **位置**：审阅与参数 → 参数表（「验收预跑B」21 参数实测）
- **现状**：出处列把 `source_ref` 与 `derivation` 两段各 80–150 字 LLM 原文全量入格（「出处说明：retrieved=检索知识中明确给出的参数（检索知识中多次出现，如“阵元数目：32”…）」×2 遍），单行 100px+，表格不可扫读。附带：单位列裸「-」（「32 -」）、双单位「1kHz–12kHz Hz」、出处裸字段路径「IR1.objectives」。
- **类别**：【违 mockup 05】（出处列 = 名称一行 + mono 公式/区间子行，详情进溯源抽屉）
- **建议**：出处列两行制（`F-01 半波长间距` + mono 表达式/区间），≥60 字截断「…展开」；全文移入抽屉；取值列 value+unit 智能拼接（unit 空/「-」不显示、值内已含单位不重复）。

### P1-2 溯源抽屉：正文裸吐 JSON、微秒 ISO 时间戳、全屏宽
- **位置**：审阅与参数 → 点参数行 → 「溯源链」抽屉
- **现状**：A2·derive 步骤正文为原始 JSON `{"name":"阵元间距","unit":"m",…}`；时间戳 `2026-09-18T15:30:51.787159Z`；抽屉 100vw 全屏。同病灶：会话页脚「创建 2026-09-18T15:49:31.438855Z · 创建人 9763204b-70ec-…」——**创建人 UUID 裸吐**（`SessionPage.tsx:181`，API 只回 created_by UUID）。
- **类别**：【违 mockup 05】（460px 抽屉、步骤中文句子 + 「14:02 · v1」短时间）
- **建议**：`width={460}`；JSON 步骤复用 ReviewAnnotation 思路转键值句（「参数 P-002 阵元间距 = 2 m（estimated）」「关联参数 P-002…P-021」）；时间统一 `YYYY-MM-DD HH:mm`；后端 session 明细 join 出 username。

### P1-3 仪表盘会话表：无分页/无操作列/无项目维度，僵尸运行无标记
- **位置**：仪表盘 → 设计会话表

- **类别**：【违 mockup 02】（操作列 + 子行 + 「查看全部 N 个会话」）
- **建议**：`pagination(10/页)` + 状态 Tab（全部/进行中/待审阅/已完成/失败）；行尾按状态给一个主动作链接；运行中会话 updated_at > 1h 加灰字「长时间无进展」（如实标注，不臆断失败）。
