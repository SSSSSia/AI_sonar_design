## 1. 总判定

审查的核心批评——**"流程能够向前运行，但参数、模型、依据、报告不总是对应同一份有效设计；部分错误或未检查项也不能可靠阻止系统给出『通过』"**——经核验**在当前版本依然成立**：

- `py-engine/solver/`（公式/复算/军标）、`py-engine/agents/a3_cad/`（几何关联）、`clients/freecad-plugin/.../executor.py`（执行器）三个关键模块 **git diff v0.4.0..HEAD 为空**，审查针对的实现原封未动；
- v0.5.0 的 E1 变更抑制（gate2 窗口/传播深度/反向确认）解决的是"变更连锁失控"，与审查指出的"正确性/覆盖面/版本一致性问题"**正交**；且"推导文本当事实存储"这一反模式被 E1 的 sync_derivation 纪律**进一步制度化**；
- v0.6.0 的重排序/审计不触及正确性主链（审计规则表只盖 KB 写+导出，检索范围不留痕）。

## 2. 逐组核验结论

证据标注：〔仍〕= 仍然存在；〔半〕= 部分修复；〔修〕= 已修复/基本修复。代码位置均为当前 v0.6.0 实测。

### 问题 1 · 公式单位不统一 —— 〔仍〕

- `py-engine/solver/formulas.py:131-140` `_first_number` 原样：纯正则抽首个数字、丢弃单位；`available_inputs`（:118-128）把 "20 mm" 抽成 20.0 直接喂给按 SI 写死的 compute 闭包——"20 mm" vs "0.02 m" 差 1000 倍的问题未变。A2 调用链 `agents/a2_scheme/agent.py:58-61` 直接把 IR1 原始字符串送入 `evaluate_available`。
- 全仓无 pint/无集中单位模块；`FormulaSpec`（formulas.py:25-44）symbols 单位只写在中文描述串里（`{"d": "阵元间距(m)"}`），不可机读、不换算、无范围。
- 唯一单位处理在几何旁路：`geometry_link.py:18` `UNIT_TO_MM` 四项长度表 + E1 diff 提案 mm↔原生换算（param_proposals.py:86-96，有单测）——不覆盖公式/军标主链。
- `solver/standards.py:14` 明文注释「单位由条目录入者自行对齐；单位换算接入列二期」。

### 问题 2 · 校验只验证"已有参数"而非"满足设计要求" —— 〔仍〕四子项全部存在

- (a) `agents/a4_validation/agent.py:189-191` 标准检查仍 `if p.get("source_type") != "standard": continue`——case/estimated 来源参数不做军标适用性核对；全仓无"必检项清单"概念。
- (b) 公式无法定位/缺代入值/复算输入不全/几何提取失败 → 全部 info 级（agent.py:84-88、92-95、107-111、311-326、378-381）。
- (c) overall 两态（agent.py:65 + `contracts/ir/ir4.schema.json:10-12` enum ["pass","fail"]），无"待验证/不完整"。
- (d) CSR 分母 = 通过+违反（agent.py:46-63 注释写死口径）：跳过/待补项不进分母，军标大面积待补时 CSR 仍可 100%——"CSR≠需求覆盖率"实质缺口无机制补上（没有必检清单就没有覆盖率分母）。

### 问题 3 · CAD 尺寸关联靠 bbox 数值接近 —— 〔仍〕

- `agents/a3_cad/geometry_link.py:46-54`：参数值(mm) 与分段 bbox 三维逐一比相对偏差，`CAD_GEO_LINK_TOL_PCT` 默认 20%（app_config.py:73），贪心一一对应——审查 100mm/150mm 漏检路径成立（偏差 50%>20% 不建链 → A4 `agent.py:342-349` 只复核"已联动"特征 → 静默跳过）。
- 无建模时参数→对象映射（features 是 STEP 生成后的后验分段，`linked_param_id` 唯一生产者就是 link_params）；不区分直径/宽度语义；SEG 编号由几何排序生成（cad_engine/geometry_inspect.py:405-415 `_finalize` 按最长轴升序 enumerate），E1 跨版本提案对齐也依赖 SEG 对位（param_proposals.py:59-62）。
- v0.5.0 微调版本化是**绕开**联动（微调版本 linked_param_id 一律 None，cad_agent/service.py:324），非修复。

## 4. 核验方法与限制

- 核验基于源码静态对照 + git 历史比对（v0.4.0..HEAD 逐目录 diff），关键断言（executor 导入、sync_derivation、apply_proposals、A4 分流、缓存键）经人工逐行复核。
- 未连真实 FreeCAD/数据库/Milvus 动态复现审查的探针实验；审查原文的【已复现】标记采信为其探针记录，本报告只对"当前代码是否仍具备该行为"负责。
- 插件执行链（T14.1）修复后需真机冒烟——本机无 FreeCAD 则如实标注待联调（A-16）。
