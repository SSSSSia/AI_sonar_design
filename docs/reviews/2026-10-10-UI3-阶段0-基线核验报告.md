## 4. 存量缺陷：biz 过期 jar（发现即修复）

- **症状**：`GET /api/v1/projects` 经网关 500「网关转发失败」；biz:8083 无监听。走查前 8083 即不在监听（上会话已死），非本次引入。
- **根因**：`biz/target/biz-0.1.0-SNAPSHOT.jar`（2026-10-07 19:08 构建）内 `BizApplication.class` 为**过期增量编译产物**——`@MapperScan` 仅含 `project`/`member`，缺 `audit`；而源码含三包、`AuditMapper/AuditRecorder.class` 又在 jar 中 → 启动即 `UnsatisfiedDependencyException: No qualifying bean of type 'AuditMapper'`。容器模式（Docker 内重新编译）不受影响，故仅宿主 `java -jar` 路径中招。
- **修复**：`mvn clean package -pl biz -DskipTests` 全量重编（新 jar 三包齐全，字节码验证通过）→ 重启 biz → 8083 监听、项目 API 200、admin 页可达性转绿、项目页恢复 100 卡片。
- **预防**：发布/启动前对 target jar 做新鲜度校验；宿主模式改 Java 代码后用 `clean package` 而非增量 package。已记入 HANDOFF 环境注意。
