# v2 路线图（唯一进度事实源）

> 状态标识：`待开发` / `开发中` / `待验收` / `完成`。每完成一个任务，状态回填必须与代码同一 commit。

## 阶段总览

| 阶段 | 名称 | 目标 | 状态 |
|---|---|---|---|
| 阶段 0 | 工程地基 | 目录骨架 + 数据底座容器化 + IR 契约初版 | 待开发 |
| 阶段 1 | 纵向闭环迁移 | A1–A3 在新架构下重组，API 级端到端跑通需求→STEP | 待开发 |
| 阶段 2 | 人在回路与校验 | A4/A5、审阅关①②、局部回环、溯源链 | 待开发 |
| 阶段 3 | 文档预处理与知识治理 | 文档上传入库管线、公式/约束/军标库、图谱可视化 | 待开发 |
| 阶段 4 | 前端工作台全量 | React 全部页面 + 三维预览 + 系统管理基础 | 待开发 |
| 阶段 5 | 验收与发布 | 发布检查清单全过，打首个 tag | 待开发 |

> 阶段 3/4 可与阶段 2 部分并行；阶段 1 完成前不动 UI（先 API 级冒烟，避免界面返工）。

| 任务 | 内容 | 状态 |
|---|---|---|

| T1.5 | A3 CAD 建模：迁移 codegen/executor 内脏（多层校验 + 修复循环），接口改 IR2→IR3，CadQuery 沙箱出 STEP | 待开发 |
| T1.6 | GraphRAG 封装迁移（sdk/service 异步包装）+ KB 索引产物接入 + 三级降级检索 | 待开发 |
