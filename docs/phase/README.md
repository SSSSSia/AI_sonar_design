## 开发路径（依赖关系）

```
阶段 0（✅）
  └─ 阶段 1 纵向闭环（T1.1✅ → T1.2✅ → T1.3✅/T1.6✅ → T1.4✅ → T1.5✅ → T1.7✅）
       └─ 阶段 2 人在回路（T2.1 → T2.2 → T2.3，T2.4 可并行）——也可与阶段 3 部分并行
             └─ 阶段 3 知识治理（T3.1 → T3.2 → T3.3 → T3.4）
                  └─ 阶段 4 前端全量（T4.1 → T4.2 → T4.3/T4.4）——每页先 mockup
                       └─ 阶段 5 验收发布（清账 → 检查清单 → v0.1.0）
```

## 每阶段开工固定动作（宪法 §7.1）

1. 该阶段文档升级为完整版（任务级接口契约/详细设计/DoD 细化）；
2. roadmap 状态改"开发中"；
3. 逐任务实现：代码 + roadmap 回填 + devlog 同 commit；
4. 阶段末：按文档验收流程走查，结论回填文档「验收记录」章节。
