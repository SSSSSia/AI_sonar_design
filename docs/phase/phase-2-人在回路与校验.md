## 1. 本期范围与边界

- 做：A4 合规校验引擎（IR3→IR4）、审阅关①②（暂停/裁决/批注/局部回环）、A5 知识沉淀（IR4 后→IR5 候选 + 知识审阅关回写）、溯源链全程记录与反查。
- 不做：知识库文档管线（阶段 3）、UI（阶段 4，本期审阅/裁决走 API）、修复策略自学习/多方案比选（暂缓项）。

## 2. 数据流（增量部分）

```
IR3（阶段 1 产物）
  → A4 合规校验（IR4：三级风险分类报告）
  → 审阅关②：人工裁决 IR3+IR4（通过 / 驳回回 A2 局部回算）
  → A5 知识沉淀（IR5 pending 候选）
  → 知识审阅关：人工确认 → 回写 Neo4j
审阅关①：IR2 后人工裁决（通过 / 驳回回 A1/A2 局部回算）——插在阶段 1 管线 A2 之后
溯源链：trace_id 贯穿 IR0–IR5 全部快照与参数，/api/v1/trace/{id} 反查
```

## 3. 任务分解

### T2.1 A4 合规校验引擎（IR3 → IR4）

- **要点**：按 source_type 分流校验（A-09 只出报告不改参数）——
  - `formula`：SymPy 等式精确代入复算（`solver/` 底座扩展）；
  - `case`：区间传播校验（自研区间算术，落在约束区间内与否）；
  - `standard`：军标条目核对（军标 0 条时如实输出"待补"，A-16）；
  - `estimated`：标注"未经公式验证"风险级。
  - 外加几何自洽检查（IR3 几何量 vs IR2 参数一致性）。
- **产出**：IR4 结构化报告（违例项 / 风险级 high|medium|low / 依据引用）。
- **DoD**：四类分流各有单测（含故意注入违例参数）；IR4 过契约校验；A4 独立 CLI；"合法 IR3 → 合法 IR4"契约测试。

### T2.2 审阅关①②（状态机暂停/裁决 + 局部回环）

- **要点**：
  - 状态机扩展：`paused` 语义落地（审阅关触发暂停），新增裁决事件（approve/reject）；
  - `review_records` 表落地批注与裁决 API：`POST /api/v1/workflow/sessions/{sid}/reviews/gate1|gate2`（宪法 §5.4 基线）；
  - 局部回环（A-11/A-12）：驳回时按 IR 版本快照回退到指定 Agent 重跑，**下游产物按需失效**（不整链路重跑）；
  - gate1 在 A2 后（审 IR2 参数表）、gate2 在 A4 后（审 IR3+IR4）。
- **DoD**：通过流 + 驳回回流各自实测（驳回→局部回算→下游失效→重跑到审阅关）；IR 版本快照全程可追溯；非审阅角色无裁决权（RBAC `gate:decide`）。

### T2.3 A5 知识沉淀（IR5 候选 + 知识审阅关）

- **要点**：从 IR2–IR4 筛选可沉淀决策（去重比对图谱已有实体）→ IR5 `pending` 候选 → 知识审阅关人工确认 → 才写入 Neo4j（A-10，禁止自动回写）；图谱不支持删实体时标 `deprecated`。
- **DoD**：候选去重单测；未确认候选绝不入图谱（断言）；确认回写 + deprecated 标记实测。

### T2.4 溯源链

- **要点**：trace_id 生成规则 + 贯穿（IR 快照 / 参数四件套 / 任务 / 审阅记录全部携带）；`GET /api/v1/trace/{trace_id}` 反查全链路（宪法 §5.4 基线端点）。
- **DoD**：任一参数从 IR2 反查到 IR0 需求原文与检索引用（E2 验收）；无 trace 的参数进不了 IR2（A-06 补强）。

## 4. 里程碑与顺序

M2-1 A4 引擎（T2.1）→ M2-2 审阅关与回环（T2.2，依赖 T1.4/T1.5 产物）→ M2-3 溯源（T2.4，可与 T2.2 并行）→ M2-4 沉淀（T2.3）→ 阶段验收（五步闭环 API 级全流程走查 + 审阅关回退流演练）。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 局部回环的下游失效逻辑复杂（改 IR2 后 IR3/IR4 作废范围判定） | 按"受影响 Agent"白名单推导失效；先固化版本快照语义再写回环；文档先行补时序图 |
| 军标库为空，standard 校验无对象 | 如实"待补"（A-16）+ 军标接入框架占位，阶段 3 首样入库 |
| 审阅关无 UI 期的裁决体验 | API + curl 脚本走查；审阅请求通知走 WebSocket（notify 模块本期激活） |
