## 1. 设计基线（mockup 阶段即锁定）

- **中性生产力美学**（Zotero/Notion 式）：拒绝装饰化；**蓝色仅用于交互/可操作语义元素**（按钮/链接/可点击态），禁止装饰性用蓝、禁止小说化 UI；
- 技术栈：React 19 + TS + Vite + AntD + Zustand + TanStack Query；三维 React Three Fiber、图谱 D3、图表 ECharts、编辑 Monaco；
- 全部请求经网关 8080（JWT），WS 消息遵循 `contracts/ws/`。

## 2. 任务分解

### T4.1 工作台仪表盘 + WS 推送 + 通知中心

- **要点**：项目/会话列表与状态总览；WebSocket 实时任务进度与日志；审阅请求通知。
- **DoD**：双浏览器会话下任务进度实时可见；断线重连恢复。

### T4.2 需求输入 + 审阅界面 + 参数表 + 校验报告

- **要点**：
  - 需求输入页（创建会话=提交 IR0，展示解析出的 objectives/missing_items 如实态）；
  - 审阅页：IR2/IR3+IR4 对照展示、批注、通过/驳回（触发局部回环）；
  - 参数表：source_type 徽标四色分类 + 溯源反查跳转（点击参数→trace 链）；
  - 校验报告：三级风险分类呈现。
- **DoD**：正常流 + gate1/gate2 驳回回流 UI 走查通过；参数 100% 可反查。

### T4.3 三维预览 + 交付物下载

- **要点**：STEP → glTF 转换服务（后端）+ React Three Fiber 前端预览（暂缓项"点击反向定位"不做）；交付物列表与下载（MinIO 预签名）。
- **DoD**：标准样例 STEP 在浏览器可交互预览；下载链路带权限校验。

### T4.4 知识库浏览 + 库管理页 + 系统管理基础

- **要点**：知识库文档列表/入库进度/实体数量诚实展示；D3 图谱可视化（T3.4 接口）；公式/约束/军标管理页；指标/日志/备份基础页。
- **DoD**：知识库现状与后端完全一致（无夸大，A-16）；管理页 CRUD 走通。

## 3. 顺序与风险

T4.1 → T4.2 → T4.3 → T4.4（T4.3/T4.4 可并行）。风险：STEP→glTF 转换依赖（对策：先验证 cadquery→glTF 直出，备选 FreeCAD/assimp 管线）；WS 在网关的转发配置（对策：Nginx/Spring Cloud Gateway upgrade 头提前验证）。

## 4. UI 验收流程（宪法 §9.4）

每页：mockup 确认 → 实现 → 真实样例走查（至少 2~3 组真实设计需求，覆盖正常流 + 审阅关回退流）→ 用户确认记录回填本文件 §5。
